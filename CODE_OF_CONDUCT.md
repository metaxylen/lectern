# Code of Conduct

We want Lectern's community to be welcoming to everyone. This project follows the spirit of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**Expected:** be respectful and patient, give and accept constructive feedback, focus on what is best for the project and
its users, and assume good faith.

**Not acceptable:** harassment, insults, personal attacks, discriminatory language or imagery, publishing others' private
information, and other conduct that would be inappropriate in a professional setting.

Maintainers may remove comments, issues and contributions that violate this code and may ban contributors who do so.
To report a problem, contact the maintainer through the email on their GitHub profile or use GitHub's private
[report content](https://docs.github.com/en/communities/moderating-comments-and-conversations/reporting-abuse-or-spam) feature.
